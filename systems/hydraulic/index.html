The three standards do not interchange

ISO 7241-A and ISO 7241-B look similar and will not couple to each other; ISO 16028 is the flat-face family, chosen where a spill matters. Pick the standard your machine uses before anything else.

Size carries the dimensions, the code carries the choice

One size has one drawing — bore, length, hex. What changes the order code is the material (carbon steel, 304, 316) and the thread (BSP or NPT). Two couplings of the same size can be different parts.

Threads and sealing

BSP and NPT are not interchangeable, and neither seals on the thread: BSPP seals on a washer or an O-ring face, NPT on the thread itself with sealant. Say which you need when ordering.
